# vzRadio

Радио со всего мира, которое подстраивается под ваш вкус. PWA на Next.js (App Router) + TypeScript + Tailwind v4, без нативных приложений — ставится на iPhone, Android, Mac и Windows прямо из браузера.

- **Весь каталог**: ~34 000 работающих HTTPS-станций из [Radio Browser](https://www.radio-browser.info) — поиск, жанры, страны, языки, топ и тренды с бесконечной подгрузкой («Обзор»).
- **Опрос вкуса** после первого запуска / входа: жанры и десятилетия → любимые артисты (фото и похожие артисты из публичного API Deezer, только метаданные) → страны и языки → реклама и разговоры. Можно пройти заново в настройках.
- **«Для вас»**: «Ваша волна» одной кнопкой, «Продолжить», станции, где *прямо сейчас* играют ваши артисты/песни, подборка по жанрам и странам.
- **Умное радио**: следит за эфиром ~80 станций (ICY-метаданные) и переносит туда, где *только что началась* ваша песня или артист; уходит от песен с 👎.
- **Без рекламы**: текущая станция проверяется каждые 10 с; когда начинается рекламный блок (маркер AdsWizz/Triton `adw_ad` или слова «реклама / werbung / reklama / advert…» в названии), плеер переключается на станцию, где играет музыка. Опция «Только музыка» так же уходит от новостей и болтовни. Работает там, где станция передаёт метаданные — у части станций реклама может проскочить.
- **Полноэкранный плеер**: обложка песни (Deezer), 👍/👎, текст песни (LRCLIB; синхронизируется, если мы застали начало песни), перемотка назад на HLS-станциях с таймшифтом.
- **Медиатека**: мои станции, песни из эфира с отметкой «в эфире», история станций и песен; статистика прослушивания.
- Фон и экран блокировки (Media Session: следующая/предыдущая станция), темы, языки ru/en/pl, синхронизация через Supabase.

Звук идёт напрямую от радиостанций; ничего не записывается и не хранится.

## Запуск

```bash
npm install
npm run dev        # http://localhost:3000
```

### Деплой на Vercel

1. Импортируйте репозиторий на vercel.com → **New Project**.
2. Переменные окружения (необязательные): `NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_ANON_KEY` — вход через Google и облачная синхронизация. Без них всё хранится в браузере.
3. На iPhone: Safari → «Поделиться» → **На экран «Домой»**.

### Supabase + вход через Google

1. Создайте проект на [supabase.com](https://supabase.com).
2. **SQL Editor** → вставьте содержимое `supabase/schema.sql` → **Run**. Создадутся таблицы `tracks`, `likes`, `playlists`, `playlist_items`, `user_artists`, `plays`, `user_state` с RLS: каждый видит только свои строки. Файл можно запускать повторно.
3. **Google Cloud Console** → APIs & Services → Credentials → **Create OAuth client ID** (Web application).
   - Authorized redirect URI: `https://<ваш-проект>.supabase.co/auth/v1/callback`
4. Supabase → **Authentication → Sign In / Providers → Google** → включите, вставьте Client ID и Client Secret.
5. Supabase → **Authentication → URL Configuration**:
   - Site URL: `https://<ваш-домен>.vercel.app`
   - Redirect URLs: `https://<ваш-домен>.vercel.app/**` (и `http://localhost:3000/**` для разработки)
6. Supabase → **Project Settings → API**: скопируйте Project URL и anon (publishable) key в `NEXT_PUBLIC_SUPABASE_URL` / `NEXT_PUBLIC_SUPABASE_ANON_KEY` на Vercel и сделайте Redeploy.

Кнопка «Войти» появится в «Медиатеке» и настройках. При первом входе локальные любимые станции и песни объединяются с облачными; дальше изменения отправляются в Supabase через 1,5 с, а при возвращении в приложение подтягиваются изменения с других устройств.

### Как получить `YT_COOKIE` (только если нужно)

1. В браузере на компьютере войдите в music.youtube.com (лучше отдельным, не основным аккаунтом).
2. DevTools (F12) → вкладка **Network** → обновите страницу → кликните любой запрос к `music.youtube.com` → **Request Headers** → скопируйте значение заголовка `cookie` целиком.
3. Вставьте эту строку в `YT_COOKIE` на Vercel и сделайте Redeploy. Никому её не показывайте — это доступ к аккаунту.

**Чтобы cookie жила долго:**
- копируйте её в окне инкогнито и сразу закрывайте окно, **не нажимая «Выйти»** (выход мгновенно отзывает cookie);
- не открывайте этот аккаунт в обычном браузере — Google «поворачивает» cookie при активности, и старая копия перестаёт работать;
- после смены региона функций на Vercel cookie может быть отозвана — скопируйте заново;
- проверить её можно в «Настройки → Проверить YouTube» (`/api/debug`): `account_ok: true` — cookie жива; `cookie_missing` — какие важные cookie не скопированы.

Если YouTube отвечает «Sign in to confirm you're not a bot» на все клиенты, сервер на 3 минуты перестаёт обращаться к YouTube, чтобы не усугублять блокировку.

## Архитектура

| Путь | Что делает |
|---|---|
| `app/api/radio/search` | Поиск по каталогу Radio Browser (имя, тег, страна, язык, сортировка, `offset` для пагинации) |
| `app/api/radio/facets` | Страны / жанры / языки со счётчиками станций |
| `app/api/radio/nowplaying` | Читает ICY `StreamTitle` у до 80 станций (сырой сокет), классифицирует: музыка / реклама / разговоры |
| `app/api/meta/*` | Deezer: жанры, артисты жанра, поиск, похожие, обложка песни |
| `app/api/lyrics` | Тексты из LRCLIB |
| `components/radio/RadioProvider.tsx` | Аудио (`<audio>` + hls.js), пул станций под вкус, опрос эфира, умное переключение, пропуск рекламы, история |
| `lib/radio/match.ts` | Сопоставление «что играет» с вашим вкусом |
| `store/library.ts` | Локальные данные (zustand + localStorage), синхронизация — `lib/cloud-sync.ts` |
